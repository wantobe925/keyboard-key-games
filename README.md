## 왜 만들었나요

컴퓨터 수업에서 아이들이 가장 많이 하는 질문은 프로그래밍에 관한 것이 아닙니다.

> "선생님, 글자가 안 지워져요."
> "Backspace랑 Delete가 뭐가 달라요?"

특수키는 글자가 적혀 있지 않거나 영어로만 적혀 있어서, 아이들은 그 키가 무슨 일을 하는지 짐작할 방법이 없습니다. **말로 설명하는 대신 직접 눌러보게 하자**는 생각에서 출발했습니다.

## 특징

- 🖥️ **가상 키보드 상시 표시** — 한국 표준 103키 배열. 눌러야 할 키가 깜빡입니다
- ✋ **손가락 안내** — 반투명 손 그림이 어느 손가락으로 누르는지 알려줍니다
- 💡 **틀려야 아는 설계** — 3번 틀리면 힌트가 자동으로 열립니다
- ♿ **색약 배려** — 정답·오답을 색과 `O`/`X` 아이콘으로 이중 표시
- 📦 **파일 하나** — 설치·로그인·서버 없음. HTML 한 개면 끝
- 📴 **오프라인 가능** — 외부 파일을 쓰지 않아 인터넷 없이도 동작합니다

## ⚠️ 한자 · 한/영 키가 안 눌릴 때

한국 키보드 고유 키라 **컴퓨터마다 신호가 다릅니다.** 이 앱은 세 가지 방법으로 대응합니다.

1. 표준 신호 인식 (`Lang1` / `Lang2`)
2. 오른쪽 Ctrl · 오른쪽 Alt로 오는 기종도 인식
3. 그래도 안 되면 → 상단 **⚙ 키 설정**에서 직접 등록

> 💡 화면 아래 가상 키보드를 **마우스로 눌러도** 모든 게임이 진행됩니다.

## 교실에서 쓰기

**추천 순서**

```
특수키 탐험대  →  키 두더지 잡기  →  문서 구조대  →  특수키 골든벨
   개념 알기        위치 익히기        기능 익히기        평가
```

- 게임 한 판은 **3~5분**이라 수업 도입·마무리 활동에 넣기 좋습니다
- 상단 **✋ 버튼**으로 손 안내를 끄면 난이도가 올라갑니다
- 컴퓨터실에서는 **🔇 음소거**를 켜주세요

`index.html`을 텍스트 편집기로 열고 아래를 찾으면 학년에 맞게 고칠 수 있습니다.
