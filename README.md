## 왜 만들었나요

컴퓨터 수업에서 아이들이 가장 많이 하는 질문은 프로그래밍에 관한 것이 아닙니다.

> "선생님, 글자가 안 지워져요."
> "Backspace랑 Delete가 뭐가 달라요?"

특수키는 글자가 적혀 있지 않거나 영어로만 적혀 있어서, 아이들은 그 키가 무슨 일을 하는지 짐작할 방법이 없습니다. **말로 설명하는 대신 직접 눌러보게 하자**는 생각에서 출발했습니다.

---

## 세 단계로 배웁니다

```
📖 키보드 배우기  →  🎯 키보드 맞춤 설정  →  🎮 게임 9종
   (3분, 14단계)        (1분, 12키)          (한 판 3~5분)
```

각 단계마다 「건너뛰기」가 있어서 급할 땐 바로 게임으로 갈 수 있습니다.

### 📖 1단계 · 키보드 배우기

키보드를 처음 만나는 아이를 위한 안내 코너입니다. 설명을 읽는 동안 **화면 아래 키보드에서 그 키가 노랗게 빛나고**, 실제로 눌러보면 칭찬해 줍니다.

| 단계 | 내용 |
|---|---|
| 1 | 키보드는 네 구역 — 숫자 줄 · 글자 키 · 특수키 · 방향키 |
| 2~9 | 특수키 하나씩 — 어디 있고, 무슨 일을 하고, 어느 손가락으로 |
| 10 | **Ctrl 짝꿍 키** — `Ctrl+C` 복사, `Ctrl+V` 붙여넣기, `Ctrl+X` 잘라내기, `Ctrl+Z` 되돌리기 |
| 11~12 | 한/영과 한자 — 한국 키보드에만 있는 키 |
| 13 | 어느 손가락이 어떤 키를 맡는지 |
| 14 | 이제 내 키보드에 맞춰볼까요 |

### 🎯 2단계 · 키보드 맞춤 설정

**이 앱의 핵심 장치입니다.** 컴퓨터마다 키보드가 달라서 생기는 문제를 처음에 한 번에 해결합니다.

특수키 12개를 하나씩 눌러보게 하고, 그때 나온 **신호를 그대로 기억**합니다. 왼쪽 Shift와 오른쪽 Shift, 왼쪽 Ctrl과 오른쪽 Ctrl도 따로 눌러 구분합니다.

키보드에 없거나 눌러도 반응이 없는 키는 이렇게 처리합니다.

| 선택 | 처리 |
|---|---|
| 🚫 이 키가 없어요 | 없는 키로 기억 → 화면 키보드로 대체 |
| 😐 눌러도 반응이 없어요 | 화면 키보드로 대체 |

건너뛴 키는 가상 키보드에 **점선**으로 표시되고, 게임 중에는 **파란 버튼**이 함께 나타납니다.

> 💡 설정은 그 컴퓨터에 저장돼서 다음부터는 묻지 않습니다.

### 🎮 3단계 · 게임 9종

| | 게임 | 학습 단계 | 배우는 키 |
|:--:|---|---|---|
| 🎒 | 특수키 탐험대 | 개념 알기 | 특수키 10개 |
| 🐹 | 키 두더지 잡기 | 위치 익히기 | 특수키 10개 |
| 🚑 | 문서 구조대 | 기능 익히기 | Backspace · Delete · Shift · Space · Enter |
| 🎹 | 키보드 밴드 | 반복 숙달 | Space · Enter · Shift · Tab · Backspace |
| 🗝️ | 특수키 방탈출 | 문제 해결 | 특수키 8개 |
| 👨‍🍳 | Ctrl 요리사 | 조합키 | Ctrl + C / V / X / Z / A |
| 🚀 | 우주 방어대 | 놀며 익히기 | Space · Shift · Ctrl · Enter · Backspace |
| 🔔 | 특수키 골든벨 | 평가 | 전체 정리 (20문제) |
| ⚔️ | 키보드 배틀 | 2인 활동 | 좌우 Shift · Ctrl 구분 |

## 특징

- 🇰🇷 **한글 이름 병기** — `Enter / 엔터`, `Caps Lock / 캡스 록`, 글자 키에는 `Q / ㅂ` 처럼 한글 자모까지
- 🖥️ **가상 키보드 상시 표시** — 한국 표준 103키 배열. 눌러야 할 키가 깜빡입니다
- ✋ **손가락 안내** — 반투명 손 그림이 어느 손가락으로 누르는지 알려줍니다
- 🖱️ **화면 키보드로도 플레이** — Shift·Ctrl은 눌린 채로 고정돼 조합키도 마우스로 가능
- 💡 **틀려야 아는 설계** — 3번 틀리면 힌트가 자동으로 열립니다
- 📐 **작은 노트북 대응** — 화면 높이에 맞춰 자동으로 줄어들어 축소 없이 씁니다
- ♿ **색약 배려** — 정답·오답을 색과 `O`/`X` 아이콘으로 이중 표시
- 📦 **파일 하나** — 설치·로그인·서버 없음
- 📴 **오프라인 가능** — 외부 파일을 쓰지 않아 인터넷 없이도 동작합니다

## ⚠️ 특수키가 안 눌릴 때

한자·한/영은 한국 키보드 고유 키라 **컴퓨터마다 신호가 다릅니다.** 오른쪽 Shift도 한글 입력 상태에서 인식이 안 되는 기종이 있고, 노트북에는 오른쪽 Ctrl이 아예 없기도 합니다.

이 앱은 네 단계로 대응합니다.

1. **맞춤 설정에서 배운 신호**를 가장 먼저 확인
2. 표준 신호 인식 (`Lang1` / `Lang2`)
3. 오른쪽 Ctrl·Alt로 오는 기종, 좌우 위치값(`location`)으로 보정
4. 그래도 안 되면 → **화면 키보드를 마우스로 클릭**

> 💡 상단 **⚙ 키 설정**에서 언제든 다시 설정하거나, 지금 누른 키가 어떻게 읽히는지 확인할 수 있습니다.

## 교실에서 쓰기

**추천 수업 흐름**

```
📖 키보드 배우기 (다 함께, 5분)
        ↓
🎯 맞춤 설정 (각자, 2분)
        ↓
특수키 탐험대  →  키 두더지 잡기  →  문서 구조대  →  특수키 골든벨
   개념 알기        위치 익히기        기능 익히기        평가
```

- 게임 한 판은 **3~5분**이라 수업 도입·마무리 활동에 넣기 좋습니다
- 상단 **✋ 버튼**으로 손 안내를 끄면 난이도가 올라갑니다
- 컴퓨터실에서는 **🔇 음소거**를 켜주세요
- 수업 전 교실 컴퓨터 한 대에서 미리 맞춤 설정을 해보시면 어떤 키가 인식되는지 확인할 수 있습니다

**문항 수정하기**

`index.html`을 텍스트 편집기로 열고 아래를 찾으면 학년에 맞게 고칠 수 있습니다.

| 찾을 내용 | 무엇 |
|---|---|
| `const LESSON=[` | 키보드 배우기 14단계 설명 |
| `const SETUP_KEYS=[` | 맞춤 설정에서 물어볼 키 목록 |
| `const QUIZ=[` | 골든벨 20문제 |
| `const Q=[` | 문서 구조대 10문제 |
| `const KOR={` | 키에 적히는 한글 이름 |

## 개인정보

이 앱은 **아무 개인정보도 수집하거나 전송하지 않습니다.** 회원가입도, 서버도 없습니다.

키보드 맞춤 설정 결과만 그 컴퓨터의 브라우저에 저장되며, 이는 "이 키보드의 Enter 키는 이런 신호를 보낸다"는 정보일 뿐 사용자와 무관합니다. 게임 점수와 기록은 창을 닫으면 사라집니다.
